# NEQO FAB — ランディングページ

長野県諏訪郡富士見町のデジタルファブリケーション工房「NEQO FAB（ねこふぁぶ）」のLP。
NEQO のファブ部門。

- 公開URL: https://shikine.github.io/neqo-fab/
- 本体は `index.html` の1枚だけ。ビルド不要、依存パッケージなし。
  フォント（Silkscreen / Space Mono）も base64 で埋め込んであるので、外部通信ゼロで表示できる。

## 構成

| ファイル | 中身 |
|---|---|
| `index.html` | LP本体。CSS・JS・フォント・ドット絵すべて内包 |
| `apps-script/Code.gs` | お問い合わせの受信スクリプト（Google Apps Script に貼る用） |

## デザインの決めごと

`index.html` 冒頭の `/* ============ TOKENS ============ */` にすべての色が集まっている。
色を変えたいときはここだけ触れば、ライト／ダーク両方に反映される。

| トークン | 役割 |
|---|---|
| `--ink` / `--paper` | 森の暗がり / 木漏れ日の紙。文字と地 |
| `--blue` | 森緑。主アクセント（ロゴ・箇条書き・アイコン） |
| `--key` | 柿色。**キーカラー＝注目させる色**。押してほしい所にしか使わない |
| `--bloom` | 木いちご色。**グラデーション専用**。文字・線には使わない |
| `--orange` | 樹皮のテラコッタ。ごく小さい装飾だけ |

守っていること:

- キーカラー（`--key`）を装飾に使わない。使う場所が増えると注目色として機能しなくなる
- グラデーションは3段構え（ページ全体 → ヒーロー → 推し活カード）で、推し活側に一番強く出す
- 小さい文字のコントラストは合成後で 4.5:1 以上。グラデーションを濃くするときは要再確認
- 推し活カードのグラデーションは透明ではなく `--mbody`（紙より明るい色）に混ぜる。
  透明で重ねると背景が暗くなり、11pxのタグ文字が読めなくなるため

## お問い合わせの流れ

```
LP のフォーム
  └ POST（no-cors）→ Apps Script ウェブアプリ
                        ├→ Google スプレッドシートに1行追記
                        └→ 通知メール送信（返信先＝相談者のアドレス）
```

設置手順は `apps-script/Code.gs` の冒頭コメントに書いてある。
デプロイして得た `/exec` のURLを、`index.html` の `var ENDPOINT='';` に貼ると動きはじめる。
貼るまでは送信ボタンが「ただいま送信の準備中です」と出て、黙って失敗しないようにしてある。

## ローカルで見る

ビルド不要。`index.html` をブラウザで開くだけ。
