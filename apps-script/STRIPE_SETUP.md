# Stripe Checkout setup

ぷくぷくネームキーホルダーの注文を、Stripe のホスト型 Checkout へつなぐための設定です。
シークレットキーは GitHub や `creator.js` へ書かず、Apps Script のスクリプトプロパティだけに保存します。

## 1. まずテストモードで設定

Stripe ダッシュボードのテストモードでシークレットキー（`sk_test_...`）を確認します。
キー自体をメール、チャット、GitHubへ貼り付けないでください。

Apps Script の「プロジェクトの設定 → スクリプト プロパティ」に次の2件を追加します。

| プロパティ | テスト時の値 |
|---|---|
| `STRIPE_SECRET_KEY` | `sk_test_...` |
| `STRIPE_MODE` | `test` |

送料は全国一律で、スマートレター210円またはレターパックライト430円を注文画面で選びます。
スマートレターは1個でA5封筒に収まる形だけ選択可能です。`STRIPE_SHIPPING_YEN` は不要です。
料金改定時は `Code.gs` と `creator.js` の送料表を更新してください。

## 2. Apps Script を更新

1. `Code.gs` と `appsscript.json` をこのフォルダの内容で更新します。
2. エディタから `checkSetup` を1回実行し、外部接続権限を含む承認を完了します。
3. 「デプロイ → デプロイを管理 → 編集」で「新バージョン」を選んでデプロイします。
4. ウェブアプリURLが変わった場合は、`creator/creator.js` の `ENDPOINT` を更新します。

## 3. テスト決済

公開前にStripeのテストカードで、決済成功・キャンセル・ブラウザを閉じた場合を確認します。
テスト注文はStripeダッシュボードとお問い合わせスプレッドシートの両方で照合します。

## 4. 本番へ切り替える前の確認

- スマートレター／レターパック料金、税込・税抜表示、返品・キャンセル条件を確認する。
- 特定商取引法に基づく表記とプライバシーポリシーを公開する。
- Stripe ダッシュボードの事業者情報、入金口座、領収メールを確認する。
- `STRIPE_SECRET_KEY` を `sk_live_...`、`STRIPE_MODE` を `live` に変更する。
- 少額の実決済と返金を1回テストする。

## 運用上の重要事項

支払い後の戻り画面はStripe Sessionを再取得して表示しますが、製作開始はStripeダッシュボードで
「成功」を確認してから行ってください。戻り画面だけを根拠に自動で印刷を始めないでください。
完全自動化する場合は、Stripe署名を検証できるWebhook受信先（Cloud RunやCloudflare Workersなど）を別途追加します。
